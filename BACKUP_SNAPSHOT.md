# Project backup

Snapshot: 22 November 2026 (Asia/Calcutta).

Includes the current Maharashtra Vision Media application source and public website media, including working changes that may not yet be deployed.

Excluded from this public repository: credentials and environment files, Git/CLI caches, dependencies, build output, private client reports/PDFs, browser screenshots, and operator-specific one-off setup scripts.

Install with npm ci and npm ci --prefix functions. Build with npm run build. Configure Firebase environment variables and Secret Manager bindings before deploying.

The complete private local snapshot, including local configuration and original Git history, is retained separately on the owner's computer.

Personal email addresses in setup documentation are replaced with example addresses. The private local backup preserves the originals.
